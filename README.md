# 📚 BookBack – Local Book Exchange Platform

A responsive web application for donating, exchanging, and discovering secondhand books locally.

🎥 **Demo Video:**


https://github.com/user-attachments/assets/1582444e-e3fd-4686-85a6-9969639cfaa1

## ✨ Features

- Browse available books
- Add new book listings
- Search books by title
- Filter books by category
- Real-time UI updates
- Responsive design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6+)
- Axios
- JSON Server
